# Выдача TOTP-кодов для Playerok

Модуль `twofa_module` использует обычный TOTP-секрет аккаунта и стандартную библиотеку Python. Дополнительные пакеты не нужны: aiogram уже входит в зависимости Playerok Universal.

Перезапустите бота и откройте `/twofa` в его Telegram-меню после авторизации. Нажмите «Привязать товар», укажите ссылку или ID своего товара, название аккаунта, Base32-секрет (или `otpauth://totp/...`) и срок доступа покупателя в часах. `0` означает отсутствие ограничения срока. По умолчанию обычный секрет даёт 6 цифр каждые 30 секунд; параметры URI поддерживают 6/8 цифр, SHA1/SHA256/SHA512 и период 15–300 секунд.

После новой оплаты покупатель получает инструкцию и может запросить код командой `!2fa` в чате оплаченного товара. Если привязанных товаров несколько, используется `!2fa ID_сделки` или `!2fa название_аккаунта`. Команду можно изменить в меню. KOSell уже обрабатывает `!код`, поэтому для совместной работы оставьте отдельную команду. Старые покупки, совершённые до подключения модуля, автоматически не добавляются.

Меню содержит список/удаление привязок, шаблон выдачи, команду покупателя, включение/выключение выдачи, автоматическую выдачу после оплаты, отметку сделки SENT после успешной отправки кода, сохранение, экспорт/импорт конфигурации и журнал. Обе автоматические опции по умолчанию выключены. SENT означает «товар передан»; окончательное подтверждение остаётся за покупателем.

Связка ищется по ID товара, затем по полному уникальному названию. Срок доступа фиксируется при оплате. Удаление привязки прекращает выдачу для неё; замена секрета также прекращает доступ прежних покупателей к новому аккаунту. Возврат сделки отзывает доступ; перед каждым кодом модуль проверяет текущую сделку через Playerok API и совпадение покупателя. При недоступности API код не выдаётся. Запросы чаще одного раза в 5 секунд игнорируются; если код истекает менее чем через 5 секунд, модуль дожидается следующего периода.

Секреты сохраняются в `module_settings/config.json`; экспорт также содержит их. Модуль пытается удалить сообщение с секретом и импортированный файл из Telegram после принятия. Секрет и код не записываются в собственный журнал или историю сделок. Для корректных кодов системные часы должны быть точными. Steam Guard использует другой формат — этот модуль предназначен для обычного цифрового TOTP.

Локальные проверки: `py -3 modules/twofa_module/tests/test_twofa.py`.
