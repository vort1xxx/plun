# Автоподнятие по группам

Откройте `/bumpgroups` в авторизованном Telegram-боте после перезапуска Playerok Universal.

1. Создайте группу и привяжите свои товары ссылками `https://playerok.com/products/...` (до 20 ссылок за сообщение).
2. Кнопкой **Время проверки** задайте ежедневное окно, например `18:00 - 20:00`. Всё время — по Калининграду (UTC+2). Окно через полночь: `22:00 - 02:00`; весь день: `00:00 - 24:00`. Начало включительно, конец исключительно.
3. Кнопкой **Частота проверок** задайте интервал между проверками внутри окна: `30 сек`, `5 мин`, `1 ч`. Число без единицы означает минуты. Допустимый интервал: 1 секунда–30 дней.
4. Задайте **Порог позиции**, например `5`: позиция `6` вызывает поднятие; позиция `5` или меньше — нет. Как и стандартная проверка позиций бота, каждая проверка запрашивает товар через `account.get_item` и использует только его поле `sequence`. Если позиции нет, автоматическое поднятие пропускается. `priority_position` и порядковый номер товара в списке аккаунта не используются.
5. Включите группу и весь модуль. Новые группы создаются на паузе: окно 18:00–20:00, интервал 30 секунд, порог 5.

Первая проверка выполняется при начале окна либо при включении группы внутри окна. Затем каждый товар проверяется с заданным интервалом. Вне окна проверки и поднятия не запускаются. Перед покупкой окно проверяется повторно; уже отправленный запрос завершится независимо от окончания окна. Планировщик опрашивает расписание каждую секунду. Сетевые запросы и последовательная обработка товаров могут задержать фактическое время проверки.

Кулдауна нет: на каждой очередной проверке товар с позицией больше порога может быть поднят снова. Режимы выбора, включения/исключения по названиям, уведомления и лимит цены удалены. Товары выбираются только по привязанным ссылкам. Кнопки расположены в две колонки.

Алгоритм автоматического поднятия повторяет штатный бот: опубликованный товар с приоритетом, отличным от DEFAULT; первый PREMIUM или платный статус из `get_item_priority_statuses`; `increase_item_priority_status` списывает стоимость с баланса Playerok. Для автоматического поднятия обычный товар сначала должен получить приоритет на Playerok. Если встроенное автоподнятие включено, модуль приостановлен — отключите его в основных настройках бота.

Кнопка **⬆️ Поднять товары** в настройках группы запускает ручное поднятие всех привязанных опубликованных товаров, включая обычные товары. Время, порог позиции и пауза автоматического расписания не учитываются. Стоимость списывается с баланса Playerok. Модуль должен быть подключён, встроенное автоподнятие — выключено. Неопубликованные и чужие товары пропускаются; блокировка неопределённого списания сохраняется. Ручной запуск не меняет настройки расписания и не выполняется параллельно с проверками планировщика. После завершения бот показывает число поднятых, пропущенных товаров, ошибок и неопределённых списаний.

Настройки сохраняются автоматически в `module_settings/config.json`; история проверок — в `module_data/state.json`, журнал — в `module_data/bumpgroups.log`. В меню есть сохранение, импорт/экспорт настроек, журнал и результаты проверок. Один товар может находиться только в одной группе. Повторная привязка переносит его. При перевыставлении товара с новым ID нужно привязать новую ссылку.

Расписание сохраняется между перезапусками; пропущенные проверки не выполняются подряд. Каждое новое дневное окно начинает проверку сразу. Ошибка с неопределённым результатом платного запроса блокирует этот товар до проверки списаний и снятия блокировки в меню. Повреждённая история не обнуляется автоматически. Импорт выключает модуль до ручного включения.

При обновлении сохраните свои `module_settings/config.json` и `module_data`: архив содержит пустые настройки. Старый период становится частотой проверок, окно по умолчанию — 18:00–20:00, старый порог 0 заменяется на 1. Группы старых режимов «все товары» и «по названиям» ставятся на паузу; привяжите товары ссылками и включите их. Удалённые настройки игнорируются при чтении и убираются при сохранении.

Офлайн-проверки без подключения к аккаунту и покупок: `python modules/autobump_groups/tests/test_autobump.py`.

В главном меню отображается причина ожидания или остановки планировщика. Ошибки чтения товара отображаются в его статусе. Если модуль выключен или группы отсутствуют, сначала настройте его через `/bumpgroups`.
