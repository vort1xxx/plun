# KOSell Rent для Playerok Universal

Модуль поддерживает любое количество ваших объявлений Playerok. Для каждого объявления отдельно задаются ссылка на товар Playerok, позиция игры KOSell и срок аренды в часах. После оплаты товара модуль заказывает аренду для его связки и отправляет логин и пароль в чат этой сделки.

## Настройка

1. Установите папку модуля в `modules` Playerok Universal и включите модуль.
2. Откройте Telegram-бот Playerok Universal, авторизуйтесь и выполните `/kosellrent` (модуль добавляет команду в стандартный список команд бота).
3. Нажмите **«Настроить ключ KOSell»** и отправьте API-ключ с доступом к каталогу и заказу аренды.
4. Нажмите **«Добавить связку товара»** и отправьте URL или ID уже опубликованного объявления Playerok.
5. Введите название игры для поиска, выберите точную позицию из каталога KOSell.
6. Введите срок аренды целым числом часов. Исходный KOSellRent ограничивает запрос значением от 1 до 720 часов.
7. Связка появится в **«Мои связки»**. Нажмите **«Добавить ещё товар»** и повторите шаги для каждого следующего объявления. У всех товаров могут быть разные игры и сроки; повторная настройка той же ссылки заменит её старую связку.

Настройки сохраняются автоматически после каждого изменения; в главном меню также есть **«Сохранить конфигурацию»**. Кнопка **«Выгрузить конфиг»** отправляет в Telegram JSON с API-ключом KOSell и всеми связками объявлений (товар Playerok, игра KOSell, часы аренды), а также валютой и шаблоном. Чтобы перенести их в плагин, используйте **«Загрузить конфиг»** и отправьте этот JSON-файл. Файл содержит секретный API-ключ — не пересылайте его посторонним.

На событии оплаченной сделки модуль проверяет ID товара, заказывает одну аренду с настроенным сроком и отправляет данные покупателю в чат Playerok. Шаблон можно изменить в Telegram; доступны `{game}`, `{login}`, `{password}`, `{hours}` и `{duration}`. В шаблоне обязательны `{login}` и `{password}`. В сообщение также добавляется подсказка Steam Guard: отправьте `!код` в чат Playerok.

Команда `!код` присылает актуальный Steam Guard код к аренде в этом чате. Если у покупателя несколько арендованных аккаунтов, он может указать логин: `!код логин`.

Если автовыдача завершится ошибкой, покупателю в чат Playerok придёт сообщение `⚠️ Возникла ошибка, я позвал продавца, чтобы он решил проблему.`, а авторизованным пользователям Telegram-бота — отдельное уведомление с причиной и ID сделки.

Если покупателю нужно снова купить товар после первой продажи, включите восстановление проданных товаров в настройках Playerok Universal. Связка ищется сначала по ID товара, затем по полному названию, если ему соответствует ровно одна связка. При одинаковых названиях нескольких связок требуется совпадение ID.

Значение `playerok.enabled: false` отключает новые заказы аренды. Шаблон выдачи проверяется до заказа: доступны только перечисленные поля без преобразований и спецификаторов формата. Для `!код` используются аренды, срок которых ещё не истёк по сохранённому времени выдачи; при повторной аренде одного логина выбирается самая новая.

Локальные проверки без обращения к API: `py -3 modules/kosell_module/tests/test_regressions.py`. При повреждении истории аренды модуль останавливает обработку с ошибкой вместо очистки истории; ошибки записи также не скрываются.

## Важно про срок в часах

Интеграция использует часовые endpoints из приложенного исходного плагина KOSellRent: `/rental/products`, `/rental/calculate-price`, `/rental/rent`, `/rental/{uid}/credentials` и `/rental/{uid}/code` на `https://www.kosell.store/api/v1`. В текущей опубликованной документации KODARIO описаны заказы аренды пакетами в днях; произвольные часы там не указаны. Поэтому возможность работы произвольного срока и Steam Guard зависит от доступности старого API и прав API-ключа. Настоящий заказ не отправляется при установке или проверке синтаксиса; его можно проверить только реальной оплаченной сделкой, и он списывает баланс KOSell.

При неопределённом результате запроса модуль не создаёт второй заказ автоматически, чтобы не списать баланс повторно. Покупателю отправляется сообщение о задержке; продавцу нужно проверить заказ в KOSell и состояние сделки. Возврат денег или изменение статуса сделки модуль автоматически не выполняет.
